# The AKit OEM Bike Pack: A Comprehensive Physics Overhaul for MX Bikes


## Executive Summary

The AKit OEM Bike Pack is a full-stack modification for the popular motocross simulator, MX Bikes, created to address the core limitations of its default physics and content. As the sole developer, I engineered a new physics model from the ground up, covering tire traction dynamics, engine performance curves, and chassis inertia, resulting in a more realistic and widely adopted riding experience. The project involved managing the entire asset pipeline from Blender to the game engine and has cultivated a significant user base, demonstrating a proven ability to deliver and maintain a complex technical product.

### Key Achievements
- **Shipped Product:** Over X thousands downloads and active community engagement.
- **Full-Stack Development:** Managed 3D modeling, physics programming, game integration, and data curation.
- **Advanced Simulation:** Implemented realistic models for tire grip, engine dyno curves, and vehicle inertia.
- **Community Management:** Released multiple updates based on user feedback, ensuring long-term project viability.

## Technical Breakdown
### The Problem - Limitations of the Base Game
- Oversimplified tire model leading to unrealistic traction and sliding behavior.
- Generic engine performance curves that didn't reflect real-world vehicle characteristics.
- Rigid asset pipeline making it difficult for the community to create and share content.

### The Solution - A Complete Physics & Content Overhaul
#### Physics Engine
- **Tire Model:** Developed a new traction model based on slip-angle calculations and empirical data, resulting in more predictable and nuanced handling.
- **Engine Dynamics:** Created a dyno system to model unique power and torque curves for each vehicle, curated from real-world data.
- **Chassis & Inertia:** Reworked mass and inertia values to provide a distinct feel for each bike class.

#### Asset Pipeline
- **Blender Integration:** Established a standardized workflow for importing custom bike models and textures from Blender into the game engine.
- **Data Curation:** Organized all physics and model data into a clean, human-readable format, empowering other creators.
