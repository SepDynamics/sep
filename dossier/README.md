# Project Dossier Framework

This folder contains planning materials for two documents:
- **Case Study**: Demonstrates the current working state of the AKit OEM Bike Pack for MX Bikes.
- **Technical Brief**: Outlines the vision and architecture of the SEP Engine.

Both files are stored as Markdown so they can be converted to PDF. A typical conversion command using `pandoc` would be:

```bash
pandoc CaseStudy_MXBikes_Physics.md -o YourName_CaseStudy_MXBikes_Physics.pdf
pandoc TechnicalBrief_SEPEngine.md -o YourName_TechnicalBrief_SEPEngine.pdf
```
