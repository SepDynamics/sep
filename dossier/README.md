# Project Dossier Overview

This folder collects materials for generating two showcase documents:

1. **The Case Study** – proofs of shipping capability.
2. **The Technical Brief** – a forward-looking architectural vision.

Each document should ultimately be exported to PDF using the filenames:

- `[YourName]_CaseStudy_MXBikes_Physics.pdf`
- `[YourName]_TechnicalBrief_SEPEngine.pdf`

The markdown templates here capture the full outline needed to create these PDFs.
